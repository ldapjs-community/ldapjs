# Security Policy

## Supported versions

Security fixes are released for the latest `2.3.x` version of
`ldapjs-community`. Older 2.x releases and ldapjs 3.x are not supported by
this fork.

| Version | Supported |
| --- | --- |
| `2.3.x` | Yes |
| `< 2.3` | No |
| `3.x` | No |

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/ldapjs-community/ldapjs/security/advisories/new)
and include, when possible:

- the affected version and environment;
- the security impact;
- steps to reproduce or a proof of concept; and
- any known mitigations or suggested fixes.

Please allow time for coordinated remediation before publicly disclosing the
issue.

## Response times

We aim to acknowledge reports within three business days and provide an
initial assessment within seven business days. We will share progress updates
at least weekly until the report is resolved or otherwise closed.

## Publishing security

Maintainers with release access must enable two-factor authentication on their
GitHub and npm accounts.
